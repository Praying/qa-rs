# QARS - HighPerformance QUANTAXIS

Rs version for quantaxis, the 'RS' both inspired by the 'RS Series' in Audi series and also the abbreviation of "Rust Language".

<img src=QUANTAXISRS.png width=20% />


qars defined several module for quant develop methods, something like
```

- standard account protocol for stock/future
    - standard / margin
    - history backtest/ realtime [sim/real account]

- portfolio protocol for multi-standard account(qifis)

- standard market 

- standard connection protocol
    - mongodb
    - clickhouse
    - rabbitmq

- standard localfile system

```
